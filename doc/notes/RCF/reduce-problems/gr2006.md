# gr2006: unresolved Reduce stack overflow

Recorded on 2026-11-06 from existing measurements and logs. No new computations
were performed for this note.

## Status

Redlog on reported a stack overflow and returned no complete marked result
in the 600-second benchmark run on 2026-11-05. Redlog off timed out. All four
Cartesian configurations completed, each returning 12,352 atom occurrences.

The failing internal procedure and cause are unknown. The logs do not
establish whether the failure occurred during DNF computation or subsequent
conversion and printing. There is no verified fix, captured native stack,
or established connection to the sumcracker-14e crash or all-diff2 memory
failure.

A standalone Reduce input exists, but only loading was validated. No
standalone DNF outcome or comparison with a newer Reduce build is recorded.

## Latest benchmark evidence

The formal rerun on **2026-11-05** used Sage and the corrected Redlog wrapper,
with **two concurrent computations** and a **600-second limit per call**.
Each call ran in a fresh spawned worker, with one timed invocation and no
warmup. Startup, input loading, and result counting were outside timing;
startup and counting had separate 30-second guards. The timed call includes
the parent/worker pipe round trip.

`600*` denotes a timeout at 600 seconds, not a completed computation time.
The equal Cartesian atom counts are reference measurements, not an independent
equivalence proof or a prediction of the size of a Redlog result.

The Redlog-on wrapper raised:

```text
RuntimeError: redcsl did not return a complete marked result:
```

The captured output printed the opening result marker and ended with:

```text
889e0d7343405c079195e7b8903c8c9e
+++ stack overflow
+++ Error bad args for stack_overflow
22:
```

The closing marker was absent. The saved status has `seconds: null` and
`output_atoms: null`. Its `returncode: 1` is the **pytest process's** exit
code, not a separately recorded Reduce exit code. The wrapper checks
`cp.returncode` before checking markers, so this error path implies a zero
exit status for the shell command `echo ... | redcsl -w`. No native CSL exit
status was recorded separately. A zero exit status would still not establish
a successful computation.

The outer execution took 303.377 seconds and the JUnit testcase duration
was 299.985 seconds. Neither is a successful DNF timing. The failure occurred
before the 600-second guard. These logs establish reported stack overflow
and incomplete output, not SIGSEGV or a garbage-collector defect.

No Flint checks were performed. The effect of concurrent execution was not
isolated. The benchmark explicitly selected the March snapshot because an
existing agent process retained an older PATH. Verify the actual executable
and its banner before a future comparison.

## Earlier observations

Before the March-snapshot refresh on **2026-11-05**, the table recorded
errors under both Redlog settings. The error causes should not be identified
with the later stack overflow without examining their own logs.

The refresh timed out at **60 seconds** under both Redlog settings. The
later Redlog-on failure under a 600-second limit is compatible with the
shorter run stopping before it could reach that failure.

Immediately before the 600-second rerun, NONE had completed with 12,352 atoms
in **18.877 seconds**; FINAL, AFTER_STEP, and DURING_STEP had 60-second
timeouts. The larger limit allowed all three to finish, with the unchanged
atom count shown above.

## Standalone diagnostic input

[gr2006.red](gr2006.red) was generated on 2026-11-05 using
`smtlib_inputs.load_input(...).as_redlog()` with Sage. It bypasses the Python
wrapper's transport and result conversion. The current file has SHA-256:

```text
89cec87a570f8d3e436f1acebf4d0ec4eba626f886482d0c83311575234dafed
```

Its current tail includes diagnostic switches added after generation:

```reduce
rlatnum gr2006;

on backtrace, gc;

on rlbnfsac, rlbnfsm;
on time;
dnf_result := rldnf gr2006$
off time;
rlatnum dnf_result;

quit;
```

The DNF is assigned without printing the full formula, then counted. The
file has no built-in timeout. Its header gives `redcsl -w < gr2006.red` as
the direct invocation from this directory.

Loading was verified with the March snapshot: 219 input atoms and 126
variables. Validation deliberately stopped before DNF. No outcome of this
standalone DNF call is recorded, with or without `backtrace` and `gc`.
The successful standalone sumcracker run must not be attributed to gr2006.
