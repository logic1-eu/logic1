There was VariableSet.__init__ for initialization, which broke the following
test. Initialization of a singleton belongs into the __new__ method.

>>> from logic1.theories.Sets.atomic import VariableSet, VV

>>> old = VV['G0001']
>>> VariableSet() is VV
True
>>> fresh = VV.fresh()
>>> str(old), str(fresh), bool(old == fresh)
('G0001', 'G0002', False)

Initial QE assumptions were not simplified until further assumptions were added.

>>> from logic1 import T
>>> from logic1.theories.Sets import Eq, Ne, qe
>>> from logic1.theories.Sets.qe import Assumptions
>>> x, y = VV.get('x', 'y')
>>> qe(T, assume=[Eq(x, x), Eq(x, y), Eq(x, y)])
T
>>> qe.assumptions
[x == y]
>>> try:
...     qe(T, assume=[Eq(x, y), Ne(x, y)])
... except Assumptions.Inconsistent:
...     print('inconsistent assumptions')
inconsistent assumptions
