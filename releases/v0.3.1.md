# Release Notes — Version 0.3.1

Released: 2026-09-14

Version 0.3.1 is primarily a bug-fix release, with numerous improvements to correctness, robustness, and packaging across Logic1.

## Corrections and Improvements

Numerous issues have been fixed across the generic quantifier elimination framework, first-order formulas, and the `Complex`, `RCF`, and `Sets` theories. These include correctness fixes in simplification, normal-form computation, parallel quantifier elimination, polynomial operations, and cardinality constraints.

## Packaging and Documentation

Logic1 now includes a `py.typed` marker for typed-package support and uses `setuptools_scm` more systematically for version information.

Runtime dependencies and optional backends are now declared more completely in `pyproject.toml`.

Numerous documentation issues, broken references, and doctests have also been fixed.
