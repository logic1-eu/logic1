# Release Notes — Version 0.3.0

Released: TBD

Version 0.3.0 introduces support for reasoning over the complex numbers, extends the quantifier elimination capabilities for Real Closed Fields, and further improves simplification and interactive use.

## Highlights

### Support for complex numbers

A new Complex theory provides first-order reasoning, including quantifier elimination, over the complex numbers. Besides arithmetic, the implementation supports, the imaginary unit $i$, real and imaginary parts $\Re$ and $\Im$, complex conjugation, and inequalities between real and imaginariy parts. See [[Faross-Sturm](https://doi.org/10.48550/arXiv.2604.26400)] for theoretical details.

### Enhanced real quantifier elimination

Quantifier elimination over Real Closed Fields has been extended with enhanced treatment of weakly parametric linear formulas, based on ideas by [Weispfenning](https://doi.org/10.1006/jsco.1997.0122). This is dynamically applied to suitable subproblems in the course of the regular elimination process.

### Enhanced real simplification

Simplification over Real Closed Fields has been further enhanced with implicit range propagation. Technically, we employ interval arithmetic to derive additional information on terms from existing bounds on variables.

### Improved interactive use

A new  module `interactive` aims at improving the convenience of interactive work with Logic1.

For Real Closed Fields, importing `interactive.RCF` imports both `firstorder`and `theories.RCF`. Furthermore, it porovides variables $a$, ..., $z$.

## Developer improvements

### Enhanced real terms and atoms

Expanded the functionality of `RCF.Term` with new operations for decomposition, simplification, and solving linear equations. Terms now allow floating-point literals as rational coefficients. Furthermore, `RCF.AtomicFormula` provides a test for weak parametricity of atomic formulas in the sense of [Weispfenning](https://doi.org/10.1006/jsco.1997.0122).

### Robustness improvements

Several issues affecting quantifier elimination and simplification have been resolved, including edge cases involving trivial formulas, unused quantified variables, parallel execution, and normal-form computation. Overall, the release provides a more robust and reliable experience for symbolic reasoning over Real Closed Fields.

### Experimental Flint backend

An experimental Flint-based implementation of `RCF.Term` has been added as an alternative to the existing SageMath-based implementation. While still experimental, it allows us to invesitigate potential performance improvements and reduced external dependencies.

## Versioning

The project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html). As this is still a `0.x` release series, APIs may evolve between minor releases.
