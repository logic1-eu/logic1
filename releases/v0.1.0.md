# Release Notes — Version 0.1.0

Released: 2024-10-29

Version 0.1.0 is the initial public release of `logic1`.

## Highlights

### Generic framework for first-order logic

Logic1 provides a framework for representing and manipulating first-order formulas, including:

- Boolean connectives
- quantifiers
- prenex normal form computation
- simplification
- quantifier elimination

Formulas are represented recursively via the abstract class `Formula` and can be processed generically across different logical theories.

## Supported theories

### Real Closed Fields

Support for formulas over real closed fields includes:

- polynomial terms based on SageMath
- equations, disequalities, and inequalities in infix notation
- simplification procedures
- quantifier elimination for quantified variables of total degree at most 2,
  based on [Košta (2016)](https://doi.org/10.22028/D291-26679)

An experimental parser for formulas from strings is also included.

### Sets

A theory of sets with cardinality constraints is provided, featuring:

- quantifier elimination
- simplification using implicit-theory techniques combined with contraction of cardinality constraints

## Generic infrastructure

The generic backend includes:

- CNF and DNF computation via [PyEDA](https://pyeda.readthedocs.io)
- generic quantifier elimination infrastructure
- optional parallel execution using Python multiprocessing
- generic simplification based on implicit theories in the style of [Dolzmann–Sturm (1997)](https://doi.org/10.1006/jsco.1997.0123)

## Support and interactive tools

Additional utility modules provide:

- concise interactive exception reporting
- logging utilities for monitoring long-running computations
- tracing decorators for debugging and execution monitoring

## Notes

- The parser infrastructure is currently experimental.
- Quantifier elimination for Real Closed Fields is currently limited to quantified variables of total degree at most 2.
- APIs and internal module structures may evolve in future versions.

## Versioning

The project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html). As this is still a `0.x` release series, APIs may evolve between minor releases.
